# dsh-frame-kit · 槽序格式钩（插件）

《第一性原理对话引擎令》要的是"回答长什么样"，此前只有 `scripts/第一性原理对话引擎.py --检` 与会话纪律，
没有常驻区块、也没有验槽工具——本炉补这一档。

## 区块 `ql:frame`（默认排序 150）

十一槽顺序（核心判断→第一性原理→先验性→全局推演→我可能错在哪→我哪里不够聪明→暴论→验证·双向回执→
我哪里没有提升→我哪里不够自主→待办清单）＋裁剪规则（闲聊裸答／短判断三槽／推演类全开）＋槽序解冻（按内容重排，
判断先行）＋回锚坐标＋双向验证槽＋防八股。

## 工具 `ql_frame`

| action | 干什么 |
|---|---|
| `验槽` | 对草稿查：缺哪几槽、槽序是否乱、核心判断有没有带置信度与一句人话；给 豁免／拦截／黄标／PASS |
| `模板` | 输出十一槽骨架（可直接贴进回答） |

## 诚实边界

- 验槽是**词面**判定：抓的是槽标记与关键词，抓不到"槽里填的是不是空话"。
- 槽是工具不是仪式：闲聊裸答豁免、短判断三槽；为过闸而灌水＝另一种违令。
- 正本以 AGENTS 为准（十一槽·提升与自主并存）；主人若改槽序，本插件跟着改。
